Apéndice — Credenciales de Google (correo real y Google Sheets)

Esto es preparación antes del taller, no se hace en vivo — toma 10-15 minutos y necesitas una cuenta de Google normal (Gmail). Todo lo de aquí es gratis: ni Gmail API, ni Sheets API, ni Drive API piden tarjeta ni facturación para el volumen de un taller.

La interfaz de Google Cloud Console cambia de vez en cuando de lugar los botones — si algún nombre no coincide exactamente con lo que ves, busca el concepto (API Library, OAuth consent screen, Credentials, Service Accounts), no el texto literal del botón.

Ambas credenciales viven en el mismo proyecto de Google Cloud, así que el paso 0 se hace una sola vez.

0. Crea el proyecto de Google Cloud

  1. Ve a console.cloud.google.com con tu cuenta de Gmail.
  2. Arriba, junto al logo de “Google Cloud”, abre el selector de proyecto → Nuevo proyecto.
  3. Dale un nombre (por ejemplo workshop-ia) y créalo. Espera a que quede seleccionado como proyecto activo (arriba, junto al logo).

Este proyecto es el que vas a usar para las dos credenciales.

1. Correo real — Gmail API (OAuth2)

Se usa en el Módulo 04 (send_email) y se reutiliza en el Módulo 05 (enviar_correo). Como el correo se envía desde tu propia cuenta de Gmail, Google exige que una persona (tú) dé su consentimiento — por eso es OAuth2 y no una clave simple.

1.1 Habilita la Gmail API

  1. En el menú lateral: APIs y servicios → Biblioteca.
  2. Busca “Gmail API” → ábrela → Habilitar.

1.2 Configura la pantalla de consentimiento OAuth

  1. APIs y servicios → Pantalla de consentimiento de OAuth.
  2. Tipo de usuario: Externo (no necesitas Google Workspace).
  3. Completa nombre de la app (ej. “Workshop IA”), tu correo de soporte y tu correo de contacto. Guarda.
  4. En Usuarios de prueba, agrega tu propia dirección de Gmail (la que va a enviar los correos). Mientras la app quede en estado Testing (no la publicas), solo las cuentas que agregues aquí pueden autenticar — y Google no pide verificación ni revisión para este modo.

1.3 Crea la credencial OAuth (tipo “Aplicación de escritorio”)

  1. APIs y servicios → Credenciales → + Crear credenciales → ID de cliente de OAuth.
  2. Tipo de aplicación: Aplicación de escritorio.
  3. Dale un nombre y créala.
  4. Descarga el JSON (botón de descarga junto a la credencial creada).

Guárdalo en tu proyecto como:

backend/credentials/gmail_client_secret.json

(La carpeta credentials/ ya está en .gitignore — nunca se commitea.)

1.4 Genera el token (una sola vez, antes del taller)

Con las dependencias del backend instaladas (pip install -r requirements.txt, incluye google-auth-oauthlib y google-api-python-client):

cd backend
python scripts/gmail_auth.py

Se abre el navegador, inicias sesión con la cuenta que agregaste como “usuario de prueba” y aceptas el permiso de enviar correo en tu nombre. Al terminar queda generado:

backend/credentials/gmail_token.json

Esta es la credencial que usa send_email/enviar_correo — no necesitas volver a correr el script salvo que el token expire o borres el archivo.

Si ves “Google no ha verificado esta app”: es normal en modo Testing. Click en “Avanzado” → “Ir a Workshop IA (no seguro)”. Como el usuario de prueba eres tú mismo, es seguro continuar.

2. Google Sheets real — cuenta de servicio

Se usa en el Módulo 05 (agregar_fila_sheet). A diferencia del correo, no hace falta que una persona inicie sesión cada vez — basta con una cuenta de servicio (una identidad propia del proyecto de Google Cloud) a la que le compartes una hoja de cálculo como si fuera otra persona con acceso de edición.

2.1 Habilita las APIs

  1. APIs y servicios → Biblioteca.
  2. Busca y habilita Google Sheets API.
  3. Busca y habilita Google Drive API (la necesita internamente la librería cliente para resolver el archivo).

2.2 Crea la cuenta de servicio

  1. IAM y administración → Cuentas de servicio → + Crear cuenta de servicio.
  2. Nombre (ej. workshop-sheets) → Crear y continuar.
  3. En el paso de permisos puedes dejarlo sin rol de proyecto (no lo necesitas, el acceso real se da al compartir la hoja) → Continuar → Listo.
  4. Entra a la cuenta de servicio recién creada → pestaña Claves → Agregar clave → Crear clave nueva → JSON. Se descarga un archivo.

Guárdalo como:

backend/credentials/google_service_account.json

Copia también el email de la cuenta de servicio (termina en ...@workshop-ia.iam.gserviceaccount.com o similar) — lo necesitas en el siguiente paso.

2.3 Comparte una hoja con la cuenta de servicio

  1. Crea una hoja de cálculo normal en sheets.google.com con tu cuenta de Gmail (por ejemplo, para el ejercicio del taller: una hoja con columnas “Nombre” y “Estado”).

  2. Botón Compartir → pega el email de la cuenta de servicio → rol Editor → Enviar.

  3. Copia el ID de la hoja: es la parte de la URL entre /d/ y /edit, por ejemplo:

    https://docs.google.com/spreadsheets/d/1AbCdEfGhIjKlMnOpQrStUvWxYz/edit
                                       └──────────── ID ────────────┘

Ese ID es el spreadsheet_id que le vas a pasar a agregar_fila_sheet.
