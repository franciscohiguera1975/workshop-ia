Del chat simple al agente con MCP, en 2 sesiones de ~2h (hasta 2h40 si da tiempo para los ejercicios 2, opcionales).

Módulos

Cada módulo (desde el 01) trae 2 ejercicios: el Ejercicio 1 es el núcleo, para todos; el Ejercicio 2 es colchón — profundiza el mismo concepto y está pensado para cuando el grupo va bien de tiempo, o como tarea para quien termina antes. Si vas justo de tiempo, el Ejercicio 2 es lo primero que se puede saltar sin perder continuidad con el siguiente módulo.

Cómo se trabaja cada módulo

  1. Lee el bloque Objetivo / Herramientas / Prerequisito al inicio.
  2. Crea o edita los archivos indicados dentro de ../backend/ (el Módulo 01 arranca de una carpeta vacía; desde el Módulo 02 vas agregando archivos sobre lo que ya construiste).
  3. Prueba con uno de estos tres métodos (el módulo te da los tres):
    • curl desde la terminal.
    • La colección de Postman en ../docs/postman_collection.json.
    • El frontend en ../frontend/ (npm run dev → http://localhost:5173).
  4. Antes de pasar al siguiente módulo, confirma el checklist del final.

El backend es uno solo que va creciendo: lo que construyes en el Módulo 01 sigue funcionando en el 02, 03, 04 y 05. El frontend no se toca en ningún módulo — ya sabe mostrar skills, fuentes RAG y llamadas a herramientas en cuanto el backend empiece a devolverlas.

Contrato del backend: crece, nunca rompe

Un único endpoint principal en todos los bloques:

POST /chat
{ "message": "...", "history": [{"role": "user"|"assistant", "content": "..."}] }

→ { "reply": "..." }                                            # Módulo 01
→ { "reply": "...", "skill_used": null }                        # Módulo 02
→ { "reply": "...", "skill_used": null, "sources": null }       # Módulo 03
→ { "reply": "...", "skill_used": null, "sources": null,        # Módulo 04/05
    "tool_calls": null }

skill_used, sources y tool_calls se agregan como campos opcionales en los Módulos 02, 03 y 04/05 respectivamente — cada uno solo cuando ese módulo introduce la capacidad que lo llena. Por eso el frontend no necesita tocarse: ya trata los tres como opcionales desde el inicio y solo muestra el panel “Ver proceso” cuando alguno viene presente.
