Módulo 00 — Bienvenida y Setup

Objetivo: tener listo lo que no se construye en el taller — el frontend (se descarga, no se programa) y la cuenta/credencial del proveedor de LLM que vas a usar. El backend se construye desde una carpeta vacía en el Módulo 01.

Herramientas: terminal, Python 3.10+, Node.js 18+, curl (o Postman).

Prerequisito: ninguno.

0.1 Qué vamos a construir

Un backend en FastAPI que vas a crear desde cero, archivo por archivo, endpoint por endpoint, y que módulo a módulo gana:

  1. Skills — instrucciones especializadas que se activan solas.
  2. RAG — respuestas basadas en documentos que tú cargas.
  3. Agentes — el modelo ejecuta herramientas (calculadora, búsquedas).
  4. MCP — esas herramientas pasan a venir de un servidor estándar.

El frontend en React, en cambio, ya está terminado — lo descargas y lo corres tal cual, para ver funcionar cada bloque del backend que vas armando.

0.2 Elegir proveedor de LLM

Todo el taller habla con el modelo por una API compatible con OpenAI (/chat/completions). Por eso el backend nunca cambia de código al cambiar de proveedor — solo cambian 4 líneas en .env. Elige una opción ahora y ten la credencial a mano (o el servidor local corriendo):

Opción Cuándo usarla Costo
Groq La más simple para el taller: rápida, sin tarjeta, soporta tool calling (necesario en el Módulo 04) Gratis (límites de uso)
OpenRouter Un solo registro, acceso a decenas de modelos gratuitos (:free) desde una sola API key Gratis (modelos :free, límites de uso)
Google AI Studio (Gemini) Registro más simple de todos (solo cuenta de Google), buena cuota gratis Gratis (límites de uso)
ChatGPT API (OpenAI) Si ya tienes una cuenta/clave de OpenAI De pago (sin capa gratuita permanente)
vLLM local Si tienes GPU propia y quieres correr el modelo tú mismo, sin depender de internet Gratis, pero requiere GPU

Las cinco funcionan sin tocar código: get_llm_client() (Módulo 01) no distingue por nombre de proveedor, solo arma el cliente con LLM_BASE_URL + LLM_API_KEY + LLM_MODEL — por eso agregar una opción nueva es siempre copiar y pegar el mismo patrón de abajo.

GitHub Models fue retirado por GitHub el 30 de julio de 2026 — ya no es una opción. Si en el futuro aparece otro proveedor con capa gratuita y API compatible con OpenAI (Mistral, Google AI Studio, Cerebras, etc.), se agrega exactamente igual: nombre, LLM_BASE_URL, LLM_API_KEY, LLM_MODEL — el código del Módulo 01 no cambia.

Groq

  1. Crea cuenta en https://console.groq.com
  2. Genera una API key en https://console.groq.com/keys
  3. Anota: LLM_PROVIDER=groq, LLM_BASE_URL=https://api.groq.com/openai/v1, LLM_API_KEY=gsk_..., LLM_MODEL=llama-3.3-70b-versatile.

OpenRouter

  1. Entra a https://openrouter.ai y crea cuenta (con email o GitHub, sin tarjeta).
  2. Ve a https://openrouter.ai/keys → Create Key → ponle un nombre → copia la key (empieza con sk-or-..., solo se muestra una vez).
  3. Elige un modelo gratuito: entra a https://openrouter.ai/models?max_price=0&supported_parameters=tools (filtra automáticamente los que son gratis y soportan tool calling, necesario para el Módulo 04) y copia su id exacto — por ejemplo nvidia/nemotron-3.5-super-vl:free. > El catálogo de modelos gratuitos cambia seguido — verifica esa > página antes del evento en vez de confiar en un nombre fijo.
  4. Anota: LLM_PROVIDER=openrouter, LLM_BASE_URL=https://openrouter.ai/api/v1, LLM_API_KEY=sk-or-..., LLM_MODEL=<el id que copiaste, con el sufijo :free>.

Google AI Studio (Gemini)

  1. Entra a https://aistudio.google.com/apikey con tu cuenta de Google (sin tarjeta).
  2. Clic en Create API key → Create API key in new project (o uno existente) → copia la key.
  3. Anota: LLM_PROVIDER=google, LLM_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/, LLM_API_KEY=<tu key>, LLM_MODEL=gemini-3.5-flash-lite (o el modelo Flash gratuito vigente — revisa https://ai.google.dev/gemini-api/docs/pricing antes del evento).

ChatGPT API (OpenAI)

  1. Genera una API key en https://platform.openai.com/api-keys
  2. Anota: LLM_PROVIDER=openai, LLM_BASE_URL=https://api.openai.com/v1, LLM_API_KEY=sk-..., LLM_MODEL=gpt-4o-mini.

vLLM local (opcional, requiere GPU)

pip install vllm
vllm serve Qwen/Qwen2.5-7B-Instruct --port 8001 --enable-auto-tool-choice --tool-call-parser hermes

--enable-auto-tool-choice hace falta recién en el Módulo 04 (Agentes). Anota: LLM_PROVIDER=vllm, LLM_BASE_URL=http://localhost:8001/v1, LLM_API_KEY=EMPTY, LLM_MODEL=Qwen/Qwen2.5-7B-Instruct.

Otro proveedor compatible con OpenAI

Cualquiera que exponga /chat/completions igual que OpenAI sirve sin cambiar código — solo repite el patrón de arriba con su propio LLM_BASE_URL/LLM_API_KEY/LLM_MODEL. Otro candidato con capa gratuita al momento de escribir esto: Mistral. Verifica límites y vigencia antes del evento — estas ofertas cambian seguido.

0.3 Descargar y preparar el frontend

El frontend no se programa en el taller — se instala una vez y queda corriendo de fondo para que, desde el Módulo 01 en adelante, veas cada endpoint nuevo funcionando en una interfaz de chat real.

cd frontend
npm install
cp .env.example .env     # VITE_API_URL=http://localhost:8000
npm run dev               # http://localhost:5173

Si lo abres ahora en http://localhost:5173 verás la interfaz, pero los mensajes van a fallar — es normal, el backend todavía no existe. Lo construyes en el Módulo 01.

0.4 Postman (alternativa a curl)

Importa ../docs/postman_collection.json en Postman. Trae una request lista por cada módulo del taller — úsala si prefieres probar cada endpoint ahí en vez de con curl.
